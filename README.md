# منصة دعوتك — Daawatak Event & Digital Invitation Platform

نظام متكامل واحترافي لإدارة وتنظيم الفعاليات والمناسبات الفاخرة، إصدار الدعوات الرقمية وتصميمها، وتتبع حضور الضيوف عبر مسح تذاكر ورموز QR الذكية.

---

## 🌟 المكونات الأساسية للنظام (Architecture)

### 1. الـ Backend (Laravel API)
* **المسار:** `/backend`
* **التقنيات:** Laravel 11, PHP 8.2+, MySQL / SQLite, Laravel Sanctum, Mail Notifications.
* **المميزات:**
  - إدارة المستخدمين والصلاحيات (Super Admin, Event Owner, Receptionist).
  - إدارة الفعاليات وقوائم المدعوين ورموز حماية الفعاليات (Event PIN).
  - واجهات برمجة آمنة وسريعة للتحقق من التذاكر ومسح الـ QR.

### 2. واجهة الويب لمنظمي الفعاليات (Frontend App)
* **المسار:** `/frontend`
* **التقنيات:** React 18, Vite, TypeScript, TailwindCSS, Radix UI, Lucide Icons.
* **المميزات:**
  - لوحة تحكم متطورة وتفاعلية لمنظم الفعالية.
  - مصمم بطاقات الدعوة الرقمية الفاخر وقوالب المناسبات.
  - إدارة قوائم الضيوف وإرسال الدعوات المخصصة.
  - صفحة **فريق الاستقبال والبوابة** لإدارة حراس البوابات وتعيين كلمات المرور ورموز الـ PIN.

### 3. تطبيق موظف الاستقبال للهاتف (Flutter Mobile App)
* **المسار:** `/Flutter`
* **التقنيات:** Flutter 3+, Dart, Mobile Scanner, Riverpod, GoRouter, Dio, Flutter Secure Storage.
* **المميزات:**
  - تسجيل دخول سريع ومباشر بكلمة المرور المسلمة للموظف أو رمز حماية الفعالية (Event PIN).
  - ماسح ضوئي عالي السرعة لقراءة رموز QR بالكاميرا مع دعم الفلاش والتبديل بين الكاميرات.
  - دعم كامل للعمل بدون إنترنت (Offline Mode) مع مزامنة فورية تلقائية.
  - شاشة نتائج ملونة وتفاعلية لتأكيد الدخول ومنع تكرار التذاكر.

### 4. لوحة تحكم مدير النظام (Admin Portal)
* **المسار:** `/admin`
* **التقنيات:** Next.js, React, TypeScript.
* **المميزات:**
  - إدارة حسابات المنظمين وموظفي الاستقبال، مراقبة الفعاليات، وسجلات التدقيق وإحصائيات النظام.

## 🚀 التشغيل السريع (Quick Start)

### 1. تشغيل الـ Backend:
```bash
cd backend
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve --port=8000
```

### 2. تشغيل واجهة الويب (Frontend):
```bash
cd frontend
npm install
npm run dev
```

### 3. تشغيل تطبيق الهاتف (Flutter App):
```bash
cd Flutter
flutter pub get
flutter run
```

## 🔒 الصلاحيات وأدوار النظام
* 🛡️ **مدير النظام (Super Admin):** إنشاء وتفعيل حسابات منظمي الفعاليات ومراقبة المنصة.
* 👑 **منظم الفعاليات (Event Owner):** إنشاء الفعاليات، إدارة المدعوين، وتعيين حراس البوابات وكلمات مرورهم.
* 📱 **موظف الاستقبال (Receptionist):** تسجيل الدخول في تطبيق الهاتف بكلمة المرور لمسح التذاكر واستقبال الضيوف.
