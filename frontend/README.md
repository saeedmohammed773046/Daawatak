# دعوتك (Daawatak) — منصة الدعوات الإلكترونية

## نظرة عامة على المشروع
- **الاسم**: دعوتك (Daawatak)
- **الهدف**: واجهة أمامية متكاملة (Frontend-only) بالكامل باللغة العربية (RTL) لإنشاء وإدارة الدعوات الإلكترونية والفعاليات، مبنية بدون أي Backend أو قاعدة بيانات حقيقية — جميع البيانات Mock قابلة للاستبدال لاحقًا بـ REST API حقيقي (Laravel أو غيره) دون تعديل واجهة المستخدم.
- **الميزات الرئيسية**: موقع تسويقي، مصادقة (تسجيل/دخول/استرجاع كلمة مرور)، لوحة تحكم مستخدم كاملة (فعاليات، ضيوف، دعوات، مصمم دعوات، قوالب، حضور مباشر، تقارير، اشتراك)، لوحة تحكم مشرف عام (مستخدمين، فعاليات، قوالب، خطط، اشتراكات، تقارير، سجلات تدقيق، إعدادات)، وواجهة استقبال مبسطة لمسح رمز QR.

## التقنيات المستخدمة
- **React 18 + TypeScript + Vite 5** (SPA — بدون Next.js لأن بيئة التشغيل هي Cloudflare Pages Sandbox)
- **React Router v6** للتوجيه مع حراسة أدوار (Public / Authenticated / Admin / Reception)
- **Zustand** لإدارة الحالة (المصادقة، الواجهة/الثيم)
- **Tailwind CSS** مع متغيرات CSS (HSL) تدعم الوضع الليلي بالكامل
- **مكوّنات على طراز shadcn/ui** فوق Radix UI Primitives
- **نظام i18n مخصص** (عربي RTL حاليًا، قابل للتوسعة لدعم الإنجليزية LTR)
- **Recharts** للرسوم البيانية (دائرية/شريطية/خطية)
- **طبقة خدمات (Services)** تفصل منطق البيانات عن الواجهات، مع بيانات Mock منفصلة تمامًا في `src/mocks/`

## الروابط
- **معاينة التطوير (Sandbox)**: يتم تشغيلها عبر PM2 على المنفذ 3000، ويمكن الحصول على رابط عام باستخدام أداة GetServiceUrl
- **GitHub**: لم يتم ربط مستودع GitHub خارجي بعد (يُنسخ العمل تلقائيًا إلى مستودع Genspark Git الخاص بالمشروع)

## بيانات تسجيل الدخول التجريبية (Mock)
لا توجد قاعدة بيانات حقيقية — الدخول يعتمد على تحديد الدور من المعرّف المُدخل:
- **مستخدم عادي**: أي بريد إلكتروني عادي (مثال: `user@example.com`) + أي كلمة مرور
- **مشرف عام**: بريد يحتوي كلمة `admin` (مثال: `admin@daawatak.com`) + أي كلمة مرور
- **استقبال**: بريد يحتوي كلمة `reception` (مثال: `reception@daawatak.com`) + أي كلمة مرور

## البنية المعمارية والبيانات
- **طبقة الخدمات** (`src/services/*.service.ts`): كل مجال بيانات (events, guests, invitations, templates, users, subscription, notifications, analytics, reports, reception, auth, contact) له ملف خدمة مستقل يستدعي `mockResolve()` من `src/lib/http.ts` لمحاكاة زمن استجابة الشبكة — يمكن استبداله بسهولة بطلبات HTTP حقيقية دون تغيير الواجهات.
- **بيانات Mock منفصلة بالكامل** (`src/mocks/*.ts`): لا توجد بيانات ثابتة داخل المكوّنات.
- **الحالات الست لكل صفحة**: Loading / Success / Empty / Error / Unauthorized / NetworkFailure — مطبّقة عبر `useAsync` hook وموحدة بمكونات `FullPageLoader`, `EmptyState`, `ErrorState`.
- **حماية المسارات**: `ProtectedRoute allowedRoles={[...]}` و `GuestOnlyRoute` في `src/components/shared/protected-route.tsx`.
- **الوضع الليلي**: مطبّق بالكامل عبر متغيرات CSS (HSL) وتبديل صنف `.dark` — يُدار من `useUiStore` (`src/store/ui.store.ts`).
- **i18n**: `src/i18n/` يحتوي `I18nProvider`/`useI18n()` وقاموسي `ar.ts`/`en.ts` — التوسعة للإنجليزية لا تتطلب إعادة بناء الواجهة (اتجاه RTL/LTR يُطبّق تلقائيًا على `<html dir>`).

## دليل الاستخدام السريع
1. زيارة `/` للموقع التسويقي، ثم "إنشاء حساب" أو "تسجيل الدخول".
2. تسجيل الدخول كمستخدم عادي → تُفتح لوحة تحكم المستخدم مع فعاليات تجريبية جاهزة.
3. تسجيل الدخول ببريد يحتوي `admin` → تُفتح لوحة تحكم المشرف العام.
4. تسجيل الدخول ببريد يحتوي `reception` → تُفتح واجهة الاستقبال (اختيار فعالية ← مسح رمز ← نتيجة).
5. تبديل الوضع الليلي واللغة متاح من قائمة الإعدادات داخل لوحة التحكم.
